#  Sales & Profit Analysis Dashboard — Power BI

An interactive **Sales & Profit Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, profitability, customers, products, regions, and business trends.

---

##  Project Overview

This project demonstrates how raw sales data can be transformed into an interactive Business Intelligence dashboard using:

- **Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**
- **Star Schema**
- **Data Visualization**

The dashboard provides a centralized view of important business KPIs and allows users to interactively analyze performance using multiple filters.

---

##  Objectives

The main objectives of this project are to:

- Analyze overall sales and profit performance.
- Monitor key business KPIs.
- Analyze sales trends over time.
- Compare sales across different product categories.
- Analyze regional sales performance.
- Identify the top-performing products.
- Explore customer demographics.
- Analyze the relationship between customer age and income.
- Provide interactive filtering for business analysis.
- Build an easy-to-use and visually intuitive dashboard.
